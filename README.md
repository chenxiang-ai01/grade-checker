# Grade Checker
A simple Python program that evaluates student scores using conditional statements.

## Features
- Accepts a score from the user
- Classifies the result as:
  - Excellent
  - Pass
  - Fail
  - Invalid score

## Concepts Used
- `input()`
- `int()`
- `if / elif / else`
- Comparison operators
